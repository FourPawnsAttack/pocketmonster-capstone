TRAINER'S MISSION GUIDE

🛡️ Mission 1: The Pokémon Class (pokemon.py)

Goal: Teach Python what a Pokémon is!

  • __init__: Save all stats to self (e.g. self.name = name, self.hp = max_hp).
  • take_damage(amount): Subtract damage from self.hp. Clamp to 0 (no negative HP!).
  • heal(amount): Add health to self.hp. Clamp so it never exceeds self.max_hp.
  • is_fainted(): Return True if self.hp <= 0, else False.
💡 Hint: Test with python3 tests/test_pokemon.py!

🌿 Mission 2: Starter Lab (starters.py)

Goal: Help Professor Oak give players their starter Pokémon!

  • Clean up player choice with choice.strip().lower().
  • Look up Pokémon data in STARTER_TEMPLATES.
  • If the choice is unknown or empty, default to "pikachu"!
  • Create and return a new Pokemon(...) object.
💡 Hint: Test with python3 tests/test_starters.py!

⚔️ Mission 3: Battle Arena Engine (battle.py)

Goal: Power attack damage math and enemy AI!

  • get_type_multiplier: Super effective = 2.0x, Not very effective = 0.5x, Neutral = 1.0x.
  • calculate_damage: Base formula is (power * attacker.attack) / defender.defense.
  • Check for 10% critical hit (1.5x damage).
  • Guarantee at least 1 damage! Return final_damage, is_critical, type_multiplier.
  • choose_enemy_move: Pick randomly using random.choice(enemy.moves).
💡 Hint: Test with python3 tests/test_battle.py!

🔴 Mission 4: Safari Catching (catching.py)

Goal: Throw Pokéballs and calculate catch chances!

  • Calculate missing HP%: (max_hp - hp) / max_hp.
  • Multiply by ball modifier (Pokéball: 1.0x, Great: 1.5x, Ultra: 2.0x).
  • Roll random.random() against total chance (max 95%).
  • Return (True, 3) on success, or (False, shakes) on escape!
💡 Hint: Test with python3 tests/test_catching.py!

🐛 Bug Catcher's Survival Tips

  • Missing Attribute: Did you forget self.hp = max_hp in __init__?
  • Returning None: Did you forget the return keyword in your function?
  • Divide by Zero: Use defense = max(1, defender.defense) to stay safe!
  • Run all tests: Type python3 run_tests.py in the terminal!
